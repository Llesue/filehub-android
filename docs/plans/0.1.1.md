# FileHub Android 0.1.1 升级计划

> 状态：计划中｜基线：v0.1.0（versionCode 1）
> 类型：patch release，不引入大功能

## 目标

修正 0.1.0 中容易误读的登录有效期展示，并处理几条低风险的体验问题。保持协议、数据库和同步行为兼容 0.1.0。

## P0：登录有效期可读性

当前「我的 → 服务器」只显示：

```
登录有效期
2027年11月22日
```

用户会把 2027 误读成近期，或不知道这是到期日。改为：

```
登录有效期
2027年11月22日到期
还剩 365 天
```

规则：

- 标题保持「登录有效期」。
- 日期后明确加「到期」。
- 第二行显示剩余天数；按本地时区计算，向上取整，最小为 0。
- 已过期时显示「已过期，请重新登录」，不再显示负数天数。
- 英文分别为 `Expires on Nov 22, 2027` / `365 days left` / `Expired. Sign in again.`
- 兼容无 `tokenExpiresAt` 的旧配置：显示 `—`，不崩溃。

验收：

- 中文/英文、浅色/深色截图各一张。
- 到期前 1 天、当天、已过期三个时间点用固定时间测试。
- 不改变 token 创建或续期逻辑。

## P1：0.1.1 候选小修

- 手动「立即同步」因 Wi-Fi/充电约束被排队时，在同步卡片上显示「已加入队列，满足条件后开始」。
- 远程目录选择器支持新建文件夹，避免为了建目录先退出同步页。
- 切换同步 root 时提示当前目标路径属于旧 root，避免保存到非预期位置。
- 通知点击后直接进入对应服务器的同步页，而不是只打开 App。
- 服务端已修复 `mkdir` 409 后，补一条契约测试；客户端继续兼容旧服务端。
