# FileHub Android 界面与功能提案

> 讨论稿 v0.2（2026-11-22）
> 已确认：底部 3 tab（服务器 / 浏览 / 我的）、浏览默认 tile 卡片行（一行一个文件），相册同步 + 目录同步 + 拍照上传进 v1。

---

## 0. 设计目标

1. **服务器是一等公民**：多 FileHub 实例切换要像切换账号一样直接。
2. **浏览优先**：进入应用两步内看到文件；不做仪表盘、推荐位、运营卡片。
3. **tile 卡片行优先**：默认一行一个文件、带边框的卡片；紧凑列表是密集信息模式的补充，不做多列缩略图墙。
4. **同步是后台能力**：设置一次后不打扰；状态、失败、冲突必须可查、可重试。
5. **缩略图是唯一彩色主体**：其余 UI 中性灰 + 单一蓝色信号色。
6. **弱网/后台可靠**：断点、重试、进程死亡恢复是硬要求。

## 1. 导航骨架

### 三 tab

```
┌──────────────────────────────────────┐
│                                      │
│              内容区                   │
│                                      │
│  ┌────────────────────────────────┐  │
│  │ 正在同步相册 · 123/500     45% │  │  ← 有任务时才出现的进度胶囊
│  └────────────────────────────────┘  │
├──────────────────────────────────────┤
│   服务器      浏览        我的        │
└──────────────────────────────────────┘
```

| Tab | 职责 |
|---|---|
| 服务器 | 多实例列表、添加/编辑/移除、选择当前实例；选中后切到浏览 |
| 浏览 | 当前实例的"位置"（本地 root + 远程目录）卡片行；进入文件浏览 |
| 我的 | 账号/配额、同步、分享、传输、外观、设备授权、关于 |

- 手机 `NavigationBar`；平板/横屏 `NavigationRail`。
- 启动默认：无服务器 → 服务器 tab；已有当前服务器 → 浏览 tab（上次位置）。
- 多选/预览时隐藏底部栏，换成操作栏或全屏。
- **分享**不是 tab：入口在"我的 → 分享管理"和文件选择栏；公开分享页是独立栈。
- **传输**不是 tab：有任务时显示进度胶囊；入口在"我的 → 传输"。
- 登录、添加服务器、公开分享页是独立栈，不显示底部导航。

### 全局返回

- 文件浏览：先退多选 → 再回上级目录 → 到 root 时回"位置"页 → 再返回切到服务器 tab/退出。
- 预览/搜索：返回恢复原列表滚动位置与选择。
- 添加服务器/登录：有未保存输入时确认放弃。

## 2. 服务器 tab

```
┌──────────────────────────────────────┐
│ 服务器                        + 添加  │
├──────────────────────────────────────┤
│ ┌──────────────────────────────────┐ │
│ │ [图标] 家里 NAS            ● 在线 │ │
│ │        https://nas.example.com   │ │
│ │        demo · 当前使用            │ │
│ └──────────────────────────────────┘ │
│ ┌──────────────────────────────────┐ │
│ │ [图标] 公司 FileHub       ● 离线 │ │
│ │        https://fh.company.com    │ │
│ │        alice · 上次 2 小时前      │ │
│ └──────────────────────────────────┘ │
│                                      │
│        还没有服务器？添加一个          │
└──────────────────────────────────────┘
```

- 卡片信息：品牌图标/首字母、实例名（可自定义）、URL、当前账号、在线状态、当前使用标记。
- **点击卡片**：设为当前实例 → 切到"浏览"tab → 显示位置页。
- 行尾 `⋮`：重新登录、测试连接、编辑名称/地址、移除（确认后撤销设备 token）。
- 在线检测：轻量 `GET /setup/status` + 已登录时 `GET /me`；失败显示原因（DNS/证书/超时/401）。
- 排序：最近使用优先；当前实例置顶。
- 添加流程：URL → 探测/品牌 → 登录 → 自动建设备 token → 成功。
- 移除服务器：二次确认，撤销设备 token；引用它的同步任务暂停并标记"服务器已移除"，配置保留，用户可删。
- 未初始化：卡片显示"未初始化"，点击给 Web 引导，不允许登录。
- 空态：插画/图标 + "添加你的第一个 FileHub" + 添加按钮。

## 3. 浏览 tab

### 3.1 位置页（root + 远程目录）

```
┌──────────────────────────────────────┐
│ [F]  [ 搜索… ]                  [⋮]  │
│ 📁 我的文件                          │
├──────────────────────────────────────┤
│ 上次：照片 / 2026 / 11      [继续]   │
│ ┌──────────────────────────────────┐ │
│ │ [📁] 照片                  [只读] ›│ │
│ └──────────────────────────────────┘ │
│ ┌──────────────────────────────────┐ │
│ │ [☁] 远程-项目              [远程] ›│ │
│ └──────────────────────────────────┘ │
└──────────────────────────────────────┘
```

- 顶部：品牌按钮（点开服务器/root 切换）+ 搜索 + 更多；没有排序/上传（位置页不需要）。
- 内容：**单列卡片行，一行一个位置**；左侧 48dp 图标容器（本地文件夹 / 远程云），右侧别名 + 只读/远程徽标 + `›`。
- 远程目录就是 FileHub 的 remote root；点进去与本地目录同样浏览。
- "上次位置"卡片：有历史时显示，点击直接回到上次目录；位置页始终保留，不自动跳转。
- root 为空/无权限：显示服务端返回原因；管理员可通过 Web 添加 root。
- 下拉刷新 roots。

### 3.2 文件浏览（默认 tile 卡片行）

> 这里的 **tile 模式 = 单列卡片行，一行一个文件**，不是 2 列网格。

```
┌──────────────────────────────────────┐
│ ← [ 搜索… ] [名称 ↑] [⬆]        [⋮] │
│ 📁 我的文件 / Phone sounds           │
├──────────────────────────────────────┤
│ ┌──────────────────────────────────┐ │
│ │ [🎵]  button8.ogg            ⋯   │ │
│ │       5.3 KB · 5 年前             │ │
│ └──────────────────────────────────┘ │
│ ┌──────────────────────────────────┐ │
│ │ [🎵]  kungfu-ringtone.mp3    ⋯   │ │
│ │       1.5 MB · 5 年前             │ │
│ └──────────────────────────────────┘ │
│ ┌──────────────────────────────────┐ │
│ │ [📁]  Phone sounds            ⋯   │ │
│ │       11-17                       │ │
│ └──────────────────────────────────┘ │
└──────────────────────────────────────┘
```

- 顶部：返回、搜索 pill、排序 chip（`名称 ↑`）、上传主按钮、更多；窄屏时排序 chip 收进 `⋮`。
- 路径条：文件夹图标 + 面包屑；第一段是 root 别名（如"我的文件"）；横向滚动，过长折叠中间。
- 卡片：白色 surface、1px `border`、12dp 圆角、12dp 内边距、卡片间距 12dp、页面左右 16dp。
- 图标容器：48×48dp、10dp 圆角、`surface-2` 底色；图片/视频用 48dp 缩略图（cover，8dp 圆角）；无缩略图用文件类型图标。
- 文本：文件名 15sp/600、单行省略；元信息 12sp/400 `text-2`（大小 · 相对时间）；目录显示修改时间。
- 行尾 `⋯`：40–48dp 触控区，打开操作菜单。
- 点击：目录进入；文件打开预览；不可预览文件弹操作 sheet。
- **上传按钮在顶栏**（参考图），不放 FAB；空目录空态里另给一个大按钮。
- 顶栏 `⋮`：紧凑列表/卡片切换、显示隐藏文件、刷新、全选、当前目录属性、同步此目录。
- 下拉刷新；滚动到底加载下一页（200/页）；骨架卡片占位。
- 同步目标目录：路径条右侧显示小同步图标，点击进入该目录的同步任务。
- 选中/按压：按压 `surface-2` 80ms；选中卡片用 `accent` 1.5px 边框 + `accent-soft` 背景，图标上叠 check。

**与参考图的差异**

- 保留：顶栏搜索 pill + 排序 chip + 上传主按钮、路径条、单列卡片行、图标容器、`⋯` 菜单。
- 不做顶部铃铛/暗色切换/头像：通知走系统通知，暗色与账号在"我的"；避免顶栏过挤。
- 不做汉堡菜单：服务器/root 切换由品牌按钮 + 服务器 tab 承担。
- 参考图只借布局密度，不复制其品牌、图标或文案。

### 3.3 紧凑列表（可选，不是默认）

```
┌──────────────────────────────────────┐
│ ← [ 搜索… ] [名称 ↑] [⬆]        [⋮] │
├──────────────────────────────────────┤
│ [缩略图]  IMG_0421.HEIC          ⋮   │
│           3.2 MB · 11-19 14:22       │
│ [图标]    合同.pdf                ⋮   │
│           1.1 MB · 11-18 09:03       │
└──────────────────────────────────────┘
```

- 无卡片边框、行高 56dp；缩略图 40dp；适合一次看很多文件。
- 视图切换记住全局；默认永远是 tile 卡片行。
- 不做 2 列/多列网格；照片多了用搜索/按时间排序，不靠缩略图墙。

### 3.4 多选

```
┌──────────────────────────────────────┐
│ ✕   已选 3 项                全选  ⋮ │
├──────────────────────────────────────┤
│ ┌──────────────────────────────────┐ │
│ │ ✓ [🎵] button8.ogg           ⋯   │ │
│ └──────────────────────────────────┘ │
│ ┌──────────────────────────────────┐ │
│ │ ✓ [📄] 合同.pdf              ⋯   │ │
│ └──────────────────────────────────┘ │
│ ┌──────────────────────────────────┐ │
│ │   [📁] 旅行                  ⋯   │ │
│ └──────────────────────────────────┘ │
├──────────────────────────────────────┤
│  ⬇    移动   复制   分享   删除  更多 │
└──────────────────────────────────────┘
```

- 长按进入多选；卡片图标上叠 check，卡片换成 `accent-soft` 背景 + accent 边框。
- 操作：下载、移动、复制、分享、删除；更多：ZIP、属性。
- 全选只选当前已加载页，滚动加载后提示是否继续全选。
- 返回/刷新/旋转保留选择；退出目录清空。

### 3.5 上传入口

```
┌──────────────────────────────────────┐
│ 上传到  照片/2026/11            关闭  │
│ ───────────────────────────────────  │
│ 🖼  照片和视频                        │
│ 📄  文件                              │
│ 📷  拍照上传                          │
│ 📁  新建文件夹                        │
└──────────────────────────────────────┘
```

- 拍照上传：调用系统相机 → cache 文件 → 直接入队；完成后可选"继续拍"。
- 选完立刻入队；底部出现进度胶囊；通知同步进度。
- 单文件 >100MB 或移动网络：先确认（大小、目标、冲突策略、仅 Wi-Fi 提示）。
- 冲突策略是账号级偏好，UI 只读显示："重名自动重命名（可在设置修改）"。
- 目录一次性上传 P1（与"目录同步"不同）。

### 3.6 状态

| 状态 | 呈现 |
|---|---|
| 空目录 | 文件夹图标 + "这里还没有文件" + 上传按钮 |
| 只读 | 顶栏锁 chip + 上传按钮隐藏 + 说明条 |
| 无权限 | 锁 + 原因 + 返回位置 |
| 网络错误 | 具体原因 + 重试 |
| 目录被外部修改 | 顶部提示"内容已更新" + 刷新 |
| 同步中 | 顶部细进度条 + 同步图标；点击看任务 |

## 4. 搜索

```
┌──────────────────────────────────────┐
│ ←  [ 搜索文件名…              ]  筛选 │
│  [全部位置]  [当前 root]              │
├──────────────────────────────────────┤
│ [缩略图] IMG_0421.HEIC           ⋮   │
│          照片/2026/11 · 家里 NAS      │
│ [图标]   合同.pdf                 ⋮   │
│          文档/合同 · 家里 NAS         │
└──────────────────────────────────────┘
```

- 全屏、自动聚焦、300ms 防抖；至少 2 字符（服务端 3 字符或 2 个中文）。
- 范围：全部位置 / 当前 root；筛选：类型、大小、修改时间。
- 空输入显示最近搜索；可单条删除/清空。
- 点击结果：文件直接预览、目录直接进入；`⋮` 提供"在文件夹中显示"（`focus` 定位）。
- 未建索引：结果区显示"创建索引"按钮 + 进度。
- 搜索历史只存本地。

## 7. 同步

### 7.1 同步中心

```
┌──────────────────────────────────────┐
│ 同步                           + 新建 │
├──────────────────────────────────────┤
│ 相册同步                              │
│   ● 相机胶卷 → 照片/手机   [单向]     │
│     上次 10 分钟前 · 待传 12 · 失败 1 │
│     [立即同步]                        │
│ 目录同步                              │
│   ● 工作 ⇄ 文档/工作       [双向]     │
│     上次昨天 · 已同步 1,204 个文件     │
│     [立即同步]                        │
└──────────────────────────────────────┘
```

- 每个任务卡片：来源 →/⇄ 目标、方向徽标、开关、上次结果、待传/失败/冲突数、进度、立即同步。
- 任务详情：选项、下次运行、失败/冲突列表、暂停/删除任务。
- 删除任务只删配置与本地映射，不删两端文件。

### 7.2 相册同步向导

```
┌──────────────────────────────────────┐
│ 相册同步                        1/4  │
│ 目标：家里 NAS › 照片/手机            │
│ 相册：12 个已选（8,421 张）  [选择]   │
│ [x] 包含视频                          │
│ [x] 仅 Wi-Fi    [ ] 仅充电            │
│ [x] 按相册分目录                      │
│ 频率：每天 ▾                          │
│ 拍摄时间：由服务器保留（需 0.2.1）     │
│              [ 下一步 ]               │
└──────────────────────────────────────┘
```

- 步骤：目标位置 → 相册 → 选项/频率 → 权限/首次扫描 → 开始。
- 相册列表显示名称、数量、封面；默认全选，可逐项取消；"选择"进入多选页。
- 选项：包含视频默认开、仅 Wi-Fi 默认开、仅充电默认关、按相册分目录默认开（`目标/<相册名>/<文件名>`）、频率（手动/每 6 小时/每天/每周）。
- 权限：Android 13+ 请求图片/视频读取；用户只给"部分照片"时明确显示"仅同步已授权照片"。
- 首次扫描：N 张 / X GB / 预计时长；开始前可取消。
- 拍摄时间：FileHub 0.2.1 起创建上传会话携带 `mtime`，服务器保留原始修改时间；旧版服务端提示升级，不阻断同步。不再默认加文件名日期前缀（可选开关，默认关）。

### 7.3 目录同步向导

```
┌──────────────────────────────────────┐
│ 目录同步                        1/4  │
│ 本地：工作（SAF 文件夹）              │
│ 目标：家里 NAS › 文档/工作            │
│ 方向：[手机→服务器] 服务器→手机  双向 │
│ [x] 忽略隐藏文件                      │
│ [ ] 删除同步（两端保持一致）          │
│ [x] 仅 Wi-Fi    [ ] 仅充电            │
│ 频率：每天 ▾                          │
│              [ 扫描预览 ]             │
└──────────────────────────────────────┘
```

- 本地文件夹用 SAF tree picker，持久化权限；目标目录用应用内目录选择器（可新建）。
- 方向：上传（默认）/ 下载 / 双向；切换方向会重新扫描并显示预览。
- 首次扫描预览：本地 N 个文件 / X GB + 远端 M 个文件；新增 / 更新 / 删除 / 冲突数量；双向且两端都非空时先警告。
- 冲突默认不覆盖：进入冲突列表，逐文件选择"用本地 / 用服务器 / 两个都保留 / 跳过"。
- 删除同步默认关：一端删除不影响另一端；开启时按方向传播，遇到另一端已修改则转冲突。
- 改名按"删 + 增"处理（v1）；任务详情明确提示。
- 双向需要 `base/local/remote` 三方基线；首次双向同步会建立基线，冲突全部列出，不自动合并。

### 7.4 运行、失败与系统限制

- WorkManager 周期任务最小 15 分钟；系统可能延迟；"立即同步"不受周期限制，可在确认后临时用移动网络。
- 同步按批执行（约 5 分钟或 100 个文件一批），每批结束保存断点；首次大批量会连续跑多批，UI 显示剩余数量，不假装一口气完成。
- 单次长任务使用前台服务通知，显示总数/当前文件/字节进度，可暂停/取消；Android 12+ 前台启动被拒时自动降级为普通任务，不崩。
- 断网、切网、杀进程后保留 `SyncEntry` 与 `uploadId`，下次继续。
- 用户"强行停止"App 后，系统不会执行后台任务，直到再次打开 App；同步卡片会明确提示。
- 单文件失败不阻塞整批；失败列表可重试/忽略/查看原因。
- 401 → 暂停任务并提示重新登录；403/只读 → 暂停并标红；413/配额 → 暂停整批。
- 旧服务端（<0.2.1）不支持 mtime：同步可继续，但提示"拍摄时间可能不准，建议升级服务器"。
- HyperOS：首次开启时引导"允许自启动 / 不限制电量"；否则周期任务可能被系统杀掉；下次运行时间只显示"约"。
- Android 15+ 前台 `dataSync` 有时限；超长任务被停止后保留断点，回前台继续。

## 8. 分享

### 8.1 我的分享

入口：我的 → 分享。列表卡片显示目标名、状态（有效/过期/已撤销）、访问量、有效期、是否有密码；操作：复制链接、二维码、编辑、轮换、撤销、删除记录。

### 8.2 创建分享

从文件/目录/多选 → 分享：

```
┌──────────────────────────────────────┐
│ 创建分享                        关闭  │
│ 合同.pdf · 家里 NAS                   │
│ 只读分享                 [开]         │
│ 密码                     [未设置]     │
│ 有效期                   [7 天 ▾]     │
│              [ 创建分享 ]             │
└──────────────────────────────────────┘
```

- 只读开启时访客只能浏览/下载；关闭后目录分享允许上传。
- 多选分享 = 文件集合；服务端限制集合内不能有目录，含目录时提示单独分享。
- 创建成功 → 链接/二维码/复制/系统分享。

### 8.3 公开分享页（免登录）

- 独立栈 + 服务端品牌名/图标；密码先解锁，ticket 存内存。
- 目录浏览、文件预览/下载；可写分享显示上传按钮。
- 过期/撤销给明确空态。
- 打开方式：我的 → 分享 → "打开分享链接"粘贴；系统分享文本 P1；自定义 scheme P1。

## 9. 平板 / 横屏

- `≥600dp`：NavigationRail + 单栏；位置/文件都用单列卡片行，内容最大宽度 840dp 居中，避免一行过长。
- `≥840dp`：仍单列卡片行；可选右侧滑出预览；常驻双栏 P1。
- 横屏视频/图片全屏；分屏按 WindowSizeClass 重排。
- 折叠屏展开不重启 Activity。

## 10. 状态与反馈

- 列表：骨架 → 内容 / 空态 / 错误；刷新保留旧内容 + 顶部细进度条。
- 破坏性操作确认：删除、覆盖、撤销分享、删除同步任务、退出、移除服务器。

## 12. 已按默认值落计划（有异议再改）

1. **服务器卡片点击**：选中并跳到"浏览"；行尾菜单才进编辑/测试/移除。
2. **位置页**：始终显示；有历史时顶部给"上次位置 → 继续"。
3. **启动默认 tab**：无服务器 → 服务器；有当前服务器 → 浏览（上次位置）。
4. **同步频率默认**：每天 + 仅 Wi-Fi；相册"仅充电"默认关；目录同步默认"上传"。
5. **相册范围**：默认全选，可逐项取消；视频默认包含；本地删除不传播。
6. **目录双向**：冲突不覆盖、逐文件解决；删除同步默认关。
7. **mtime**：依赖 FileHub 0.2.1；旧服务端降级提示，不阻断。
8. **管理端/文本编辑/平板双栏/生物识别**：P1。
9. **低版本**：`minSdk 26`；API 26 用 Robolectric + 发布前借机/云真机冒烟。
10. **视觉**：沿用 FileHub Web 中性 Drive 风（蓝 `#1A73E8`、浅灰底、缩略图唯一彩色）。

唯一还需要与后端对齐的是：FileHub 0.2.1 的 `mtime` 到底放在 `POST /uploads` 还是 `complete`；客户端先按 `POST /uploads` 实现，接口定稿后 1 行适配。
