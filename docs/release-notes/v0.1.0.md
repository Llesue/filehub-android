# FileHub Android 0.1.0

First public build of the native FileHub Android client.

## Highlights

- Multiple FileHub servers with address failover in the configured order (put a LAN address first); drag the handles in Add Server / Edit Server to reorder
- Compact file browser, folder sizes and a persistent directory cache
- Image preview with swipe paging, double-tap 1:1 zoom, blurred backdrop, EXIF and download
- Media3 video/audio playback with controls synchronized with the title and rotate button
- Markdown tables, task lists, strikethrough and links
- Resumable background uploads/downloads, transfer center and per-server sync
- Photo sync with separate photo/video Wi-Fi policies and Wi-Fi catch-up
- Folder sync with upload/download/two-way modes and conflict protection
- Remote folder picker for sync destinations, with new-folder creation and paginated loading
- Sync notifications open the matching server's photo/folder sync screen
- Share links, public share viewer, QR codes, themes and system-following language
- Adaptive FileHub launcher icon

## Fixed in this build

- Delete confirmation shows the 4-digit server code; folder deletion was previously blocked because the code was not visible.
- Sign-in validity reads as an expiry date with remaining days.
- Edit Server address fields dismiss the keyboard on Done again.
- Manual sync explains when the run is queued behind Wi-Fi/charging constraints.
- Switching the sync root warns that the target path will be recreated under the new root.

## Notes

- Android 8.0 (API 26) or newer.
- FileHub 0.2.1 or newer preserves original photo timestamps; older servers upload with the current time.
- Background sync is WorkManager-based and best-effort. OEM battery restrictions or force-stop can delay it. On Xiaomi, set battery usage to unrestricted and allow autostart/notifications.
- Manual sync respects the configured Wi-Fi/charging constraints.
- If the device token expires or the configured target root disappears, the affected sync is disabled until it is reconfigured.
