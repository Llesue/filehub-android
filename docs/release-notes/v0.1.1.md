FileHub Android 0.1.1 focuses on the rough edges found while using the 0.1.0 client every day.

Remote mounts now tell you when they are offline, cache the last listing instead of showing an empty folder, and make directory/photo sync fail once with a clear message instead of writing one error per file. Images got a more natural zoom and a single-tap chrome toggle, plus a quick switch to the original. The browser has a camera shortcut, uploads refresh the folder they landed in, and delete confirmation shows every selected item with a focused numeric code field.

Text handling is the largest change: the client uses the server's content probe instead of trusting file extensions, supports Windows-era encodings with lossy warnings, shows line numbers for code, and ships a basic full-screen editor for text and raw Markdown. Saving uses If-Match, so a second editor gets a conflict instead of silently overwriting.

The rest of the release fills in API surface that already existed on the server: job progress for copy/move/ZIP/unzip, quota, server version and search index state, share editing, audio track selection/transcoding, thumbnail retry and richer image EXIF. A global MediaSession audio player keeps music playing across folders and screens.

This is a patch release with a lot of features. Code syntax highlighting is intentionally not included.
