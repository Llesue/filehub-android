# FileHub Android 0.1.5

## English

Highlights:
- Added SHA-256 content hashing to photo and folder sync, with upload verification, content-based dedupe and safe fallback for servers or remote roots without hash support.
- Rebuilt sync reliability around a shared run state, a live four-step state machine, bounded logs, richer notifications and per-file conflict resolution.
- Password resets and expired device tokens can now be recovered inside the app without deleting the server profile or losing sync configuration.
- Polished the responsive UI with draggable server cards, one card layout across phone, landscape and tablet, clearer root and share management, and relative share expiry labels.

New:
- Photo and folder sync share one run state with phase, block and cancel reasons, run id, heartbeat, item and byte progress, and stop/cancel flags.
- Each sync kind keeps a bounded 200-entry log of starts, scans, plans, progress, failures and completions in the right-hand pane.
- SHA-256 hashing runs as a local stream, caches per entry, detects server capability, verifies uploads, compares same-name content and dedupes same-size files across names.
- The sync status card shows a four-step state machine with prepare/scan/apply/done for photos and scan/compare/apply/done for folders.
- Sync notifications show overall bytes and counts, the current file, transfer speed, stop/cancel/continue/retry actions, a completion summary and a privacy-safe lock-screen version.
- Folder sync has a conflicts page that resolves each file as keep-phone or keep-server and then re-syncs automatically.
- Share cards use two columns on wide screens while keeping copy, QR and open actions on every card.

Improved:
- Sync settings lock while a run is active, and the save button reflects dirty, saving, saved, running and target-changed states.
- Sync notifications are throttled and still work when notification permission is denied.
- Sync logs keep one line per entry with ellipsis for long text; starts are blue, successes green, failures red, warnings amber and timestamps a lighter grey.
- The shares top bar no longer offers a paste-a-share-link entry; copy link and the QR card remain.
- All four utility pages use a 48dp compact toolbar, and the sync save action moved into the toolbar.
- Photo and folder sync put options on the left and the live state machine plus log on the right, collapsing to one column below 720dp with the log in a dialog.
- The shares page no longer has a search field or filter chips, and the card grid uses the full page width.
- Sync storage targets use a full-width picker with yellow folder icons, hidden offline or read-only roots, local/remote labels and a top-right close button.
- Selecting a remote root shows a small circled warning whose explanation covers the name/size/mtime fallback for content hashing.
- Remote roots in the browser show the sharer's avatar with a coloured initial fallback, and their Remote/Online badges stay on the name row while long names ellipsize.
- Root cards use a bare yellow folder icon instead of a grey icon tile, while folder contents keep their existing style.
- The sync root field shows Remote as a blue inline badge on the same line as the directory name.
- First sign-in and admin password resets are handled in the app by collecting a new password and calling the forced-change endpoint before creating the device token.
- An expired server token opens a prefilled sign-in screen with only the password field, and the existing profile id keeps photo and folder sync configuration attached.
- Server cards show a cached `vX.Y.Z` badge, fetched for the active server and refreshed for the others when the list opens.
- An expired server card shows a sign-in-again badge instead of a long error, and tapping it opens the re-authentication screen.
- Server cards can be reordered by long-press drag in the phone list and the landscape/tablet picker, with the dragged card following the finger and the others animating into place.
- Phone, landscape and tablet server cards share one layout with the server icon, account name, version badge and re-authentication badge.
- Add-server, re-authentication and edit-server forms use a centred, width-limited column on landscape phones and tablets.
- Share management now calls the stop action "Stop sharing" and the rotate action "Reset link", matching the server and web UI.
- Stopped and expired share cards are dimmed, disable copy/QR/open and only offer enable and delete in their menu.
- Re-enabling an expired share extends it by one day like the web UI, and the edit dialog no longer carries a redundant pause switch.
- Active share cards show a relative expiry such as "Expires in 3 days" instead of a generic Active label.

Fixed:
- MediaStore buckets that report the same bucket id under `Camera` and `camera` now resolve to one canonical album name in both the picker and the uploader.
- Changing a sync target cancels the old worker and marks the run as target-changed instead of writing into the old folder.
- A finishing worker can no longer overwrite a newer sync configuration; only its result fields are updated.
- Folder sync clears its three-way baseline when the target or direction changes, so the next run compares against the right target.
- Delete sync refuses to run when its target overlaps the photo sync target.
- Photo and folder sync can no longer run at the same time for one profile; the later run reports that another sync is running.
- Saving an overlapping folder/photo target now requires explicit confirmation.
- Stale active runs are shown as interrupted instead of a frozen progress bar.
- Servers without hash support, or hash endpoints returning 404/501, fall back to size plus mtime without blocking sync.
- A `HASH_MISMATCH` response clears the upload session so the next run starts a fresh upload instead of reusing it.

## 中文

本次亮点：
- 相册与目录同步加入 SHA-256 内容哈希，支持上传校验、按内容去重，并在旧服务端或远程目录上安全回退。
- 同步可靠性整体重做：共享运行状态、四步状态机、有界日志、完整通知和逐文件冲突处理。
- 密码重置和设备授权过期可以在应用内恢复，不用删除服务器配置，也不会丢同步设置。
- 响应式界面继续打磨：服务器卡片可拖动排序，手机、横屏和平板共用一套卡片，根目录与分享管理更清晰，分享显示相对过期时间。

新增：
- 相册和目录同步共用一套运行状态，包含阶段、阻塞/取消原因、运行 id、心跳、文件与字节进度，以及停止/取消标记。
- 每种同步保留最多 200 条的有界日志，记录开始、扫描、计划、进度、失败和完成，显示在右侧。
- SHA-256 使用本地流式计算并按条目缓存，自动探测服务端能力，校验上传，比较同名内容，并对同大小不同名文件做内容去重。
- 同步状态卡显示四步状态机：相册是准备/扫描/应用/完成，目录是扫描/比较/应用/完成。
- 同步通知显示总字节和数量、当前文件、传输速度、停止/取消/继续/重试操作、完成摘要，以及隐私安全的锁屏版本。
- 目录同步提供冲突页，可逐文件选择保留手机或保留服务器，处理后自动重新同步。
- 宽屏分享卡片改为两列，同时保留每张卡片的复制、二维码和打开操作。

完善：
- 同步运行期间设置会锁定，保存按钮会显示未保存、保存中、已保存、运行中和目标已变化等状态。
- 同步通知做了节流，通知权限被拒绝时也不会中断同步。
- 同步日志一条一行，长文本省略；开始为蓝色、成功为绿色、失败为红色、警告为琥珀色，时间戳使用更浅的灰色。
- 分享页顶栏移除粘贴分享链接入口，保留复制链接和二维码卡片。
- 四个工具页统一使用 48dp 紧凑工具栏，同步保存操作移进工具栏。
- 相册和目录同步把选项放在左侧，实时状态机和日志放在右侧；低于 720dp 时收成单列，日志改为弹窗。
- 分享页移除搜索框和筛选标签，卡片网格使用整页宽度。
- 同步存储目标改为全宽选择器，使用黄色文件夹图标，隐藏离线或只读目录，显示本地/远程标签，右上角关闭。
- 选择远程目录时会在“存储”旁显示小圆圈警告，点开后说明远程目标不支持内容哈希，会回退到名称、大小和修改时间。
- 浏览器里的远程目录显示分享者头像和彩色首字母兜底，远程/在线徽标留在名称行，长名称省略而不是挤走徽标。
- 根目录卡片改用裸露的黄色文件夹图标，去掉灰色图标底，文件夹内容不变。
- 同步根目录字段把“远程”做成蓝色内联徽标，和目录名在同一行。
- 首次登录和管理员重置密码都在应用内处理：先收集新密码并调用强制改密接口，再创建设备 Token。
- 设备 Token 过期时打开预填地址和用户名的重新登录页，只填密码，并保留原有 profile id，使相册/目录同步配置继续挂在该服务器上。
- 服务器卡片显示缓存的 `vX.Y.Z` 版本徽标，当前服务器主动拉取，打开列表时刷新其他服务器。
- 过期服务器卡片显示“需要重新登录”徽标而不是长错误句，点卡片直接进重新登录页。
- 手机列表和横屏/平板选择器都支持长按拖动服务器卡片排序，被拖卡片跟手，其他卡片滑动让位，松手立即保存顺序。
- 手机、横屏和平板服务器卡片共用一套布局，统一显示服务器图标、账号名、版本徽标和重新登录徽标。
- 添加服务器、重新登录和编辑服务器表单在横屏手机和平板上使用居中限宽布局，不再横向拉满。
- 分享管理把“撤销”改为“停止分享”，把“轮换链接”改为“重置链接”，与服务端和网页端一致。
- 停止或过期的分享卡片会半透明，复制/二维码/打开按钮禁用，菜单只保留“启用分享”和“删除分享”。
- 过期分享重新启用时自动延长 1 天，与网页端一致；编辑分享去掉了重复的“暂停分享”开关。
- 有效分享卡片显示相对过期时间，例如“过期：3天后”，不再只显示“有效”。

修复：
- MediaStore 里同一 `BUCKET_ID` 的大小写变体（例如 `Camera` 和 `camera`）现在会在选择器和上传器里归并为同一个相册名。
- 修改同步目标会取消旧 worker，并把运行标记为“目标已变化”，不再继续写入旧目录。
- 正在收尾的 worker 不能再覆盖更新的同步配置，只更新结果字段。
- 目录同步在目标或方向变化时清空三方基线，下一次运行按正确目标比较。
- 删除同步与相册同步目标重叠时拒绝运行。
- 同一 profile 的相册同步和目录同步不能同时运行，后启动的一方会提示已有同步在运行。
- 保存与相册同步重叠的目录目标时必须显式确认。
- 过期的运行中状态显示为“已中断”，不再停在假进度条。
- 服务端不支持哈希，或哈希接口返回 404/501 时，自动回退到大小+修改时间，不阻塞同步。
- 收到 `HASH_MISMATCH` 时清除上传会话，下一次从新上传开始，不再复用旧会话。
