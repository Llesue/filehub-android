# FileHub Android 0.1.11

## English

Added:
- App lock with fingerprint, face or device screen lock. Locks on cold start and after one minute in the background; enabling and disabling require authentication.
- Video preview playlist: swipe up/down or use the player's previous/next buttons to switch videos in the current folder. The current frame slides out and the next one slides in after its first frame; the next few seconds are preloaded and a spinner shows while waiting. Playback advances automatically at the end and stops on the last file. Unsupported codecs show a clear message instead of a black screen, and swiping after an error moves on to the next item instead of getting stuck. Music resumes only when the preview closes.
- Full, untruncated file names and absolute modified times in file details.
- Image/video previews keep the underlying list at the current item.

Changed:
- Browsing defaults to newest-first list mode. Switching list/grid returns to the top, while per-directory sort, view and scroll positions remain saved.
- File properties and details are both labelled “Details”.

Fixed:
- No more “No servers yet” flash while saved profiles load on tablet, landscape and phone layouts.

## 中文

新增：
- 应用锁：支持指纹、人脸或系统锁屏密码。冷启动锁定，退到后台满 1 分钟再回来锁定；开启和关闭都要先验证。
- 视频预览改为当前目录的播放列表：上下滑或播放器自带的上一/下一首按钮切换视频，切换时显示加载转圈；视频播完自动下一个，最后一个停住；不支持的编码显示提示，失败后继续滑会跳到下一集，不会卡死。音乐只在关闭预览时恢复。
- 文件详情显示完整不缩略的文件名，修改时间改为绝对时间。
- 图片/视频预览切换时，底层文件列表同步到当前条目。

调整：
- 文件浏览默认按修改时间倒序、列表模式。切换列表/网格会回到顶部，同时保留每个目录自己的排序、视图和滚动位置。
- 文件属性/详情统一叫“详情”。
- 文件类型图标改用 FileHub 网页版同款 24dp 线性图标，覆盖 22 个分类；新增应用、库文件、安装包、快捷方式、配置文件类型，并跟随网页版亮/暗配色。

修复：
- 平板、横屏和手机布局在读取本地服务器配置时不再先闪“还没有服务器”。
