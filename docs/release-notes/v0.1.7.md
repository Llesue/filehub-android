# FileHub Android 0.1.7

## English

Highlights:
- Photo and folder sync rebuild their periodic WorkManager job on startup if an update, force-stop or system cleanup removed it.
- The sync settings screen now shows the real schedule state and next run time instead of only the saved configuration.
- Manual mode no longer schedules a hidden daily job, and changing only the schedule no longer resets the incremental scan.

New:
- Startup reconciliation recreates the periodic photo and folder sync job when it is missing or cancelled.
- The settings screen shows whether the periodic job is scheduled, its next run time, and a rebuild action when it is missing.
- Manual frequency is now a real manual mode: no periodic job and no overdue catch-up.

Improved:
- The sync action row keeps Full sync on the left and the daily action on the right.
- Album IDs are compared as sets and stored in sorted order, so a schedule-only save no longer forces the next run into a full scan.

Fixed:
- A lost or cancelled periodic job no longer leaves the settings screen showing a healthy schedule with no background work.
- An app update or force-stop no longer requires the user to save the sync settings again before automatic sync resumes.

## 中文

本次亮点：
- 相册和目录同步在应用启动时自动检查和重建周期任务，升级、强制停止或系统清理后不再静默失效。
- 同步设置页显示真实的调度状态和下次运行时间，不再只显示保存的配置。
- 手动模式不再偷偷排每天任务；只改同步频率也不会再重置增量扫描。

新增：
- 启动自愈：周期任务丢失或被取消时，自动为相册和目录同步重建任务。
- 设置页显示周期任务是否已排定、下次运行时间，以及未排定时的“重建”操作。
- 手动频率现在是真正的手动模式：不排周期任务，也不做过期补跑。

完善：
- 同步操作行保持“全量同步”在左，“日常同步”在右。
- 相册 ID 按集合比较并按排序存储，只改同步频率不会再让下一次运行变成全量扫描。

修复：
- 周期任务丢失或取消后，设置页不会再显示“正常”的假状态。
- 应用升级或强制停止后，不再需要用户重新保存同步设置才能恢复自动同步。
