# FileHub Android 0.1.3

## English

Fixed:
Moving or copying files from subdirectories now sends root-relative paths, so bulk operations no longer fail with “not found”.
The move/copy directory picker no longer offers manual path entry; manual entry remains available for sync targets.
A lost server connection marks the active server offline on the server page.
The directory retry now re-probes every configured address and reloads the folder after reconnecting.

## 中文

修复：
子目录里的移动或复制现在会发送带当前目录的完整相对路径，多选操作不再报 not found。
移动到 / 复制到的目录选择器不再显示“手动输入”，同步目标仍保留手动输入。
服务器断联后，“服务器”页会把当前服务器显示为离线。
目录页的“重试”现在会重新按地址顺序连接服务器，连接成功后自动刷新当前目录。
