# FileHub Android 0.1.10

> **Critical fix — upgrade strongly recommended.**
> 0.1.9 can fail uploads to newly nested album paths (`DCIM/Camera`, `Music/MV`) and leave sync incomplete. 0.1.10 fixes it.
> **重大缺陷修复 —— 强烈建议升级。** 0.1.9 在新嵌套相册路径下会创建不了父目录，导致同步大量失败。

## English

Fixed:
- Remote photo directories are now created top-down from the storage root. A missing intermediate folder such as `DCIM` or `Music` no longer causes `parent directory does not exist`; nested album paths like `DCIM/Camera` and `Music/MV` upload correctly.

## 中文

修复：
- 远端相册目录改为从存储根目录开始逐段创建。缺少 `DCIM`、`Music` 这类中间目录时不再报 `parent directory does not exist`，`DCIM/Camera`、`Music/MV` 等嵌套路径现在能正常上传。
