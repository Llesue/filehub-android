# FileHub Android 0.1.12

## English

Added:
- A delete action in the image and video preview top bar using the existing confirmation flow. It moves to the next item, falls back to the previous one, or closes the preview, and is hidden on read-only roots.

Fixed:
- The video switch spinner now disappears as soon as playback is ready or playing, including transitions where Media3 does not emit another first-frame event. The 15-second safety timeout no longer reports “cannot play” while the video is actually playing.
- Avatars are cached per profile and user, so switching accounts on the same server no longer shows the previous user's avatar. Re-authenticating the same profile also rebuilds the image loader when its token changes.

## 中文

新增：
- 图片/视频预览顶栏增加删除按钮，复用现有删除确认；删除后自动切到下一项，没有下一项则回到上一项，最后一项删除后关闭预览；只读目录不显示。

修复：
- 视频切换的转圈会在播放器就绪/开始播放后立即消失，包括 Media3 不再发送首帧事件的播放列表切换；15 秒兜底不会在视频实际正在播放时误报“无法播放”。
- 头像按 profile 和用户分别缓存，同一服务器切换账号后不再显示上一个用户的头像；同一 profile 重新登录、token 变化时会重建图片加载器。
