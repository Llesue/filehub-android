# FileHub Android 0.1.2

## English

New:
Long-press multi-select with a persistent bottom action bar and a create/upload FAB.
List and grid views with card-style tiles, sharper shared thumbnails and per-directory sort, view and scroll state.
Multi-file collection shares, QR card images and permanent share deletion.
A unified document screen with in-place editing, a collapsible title and per-file wrap settings.
Independent fullscreen for images and videos, plus music resume after a video ends or closes.
A unified directory picker with root switching and recursive creation of missing target folders.
Client update checks with a new-version chip beside the client and server versions.
APK recognition and additional icon fallbacks for e-books, fonts, disk images, design files and torrents.

Improved:
File names keep their suffixes when middle-ellipsized, including APK, AAB, EPUB, font, disk-image, design-file, torrent and subtitle formats.
Text and Markdown preview and edit now share the same 15sp/23sp typography and 16dp content margins.
Large code files stay responsive in the editor by skipping syntax colouring above 40k characters.
Share cards omit the raw URL and use larger, centred expiry and scan hints with a safe bottom margin.
The account page shows quota as a compact ring; version details sit directly under the server card.
The document page colour now also paints the status bar, header and bottom status bar.
List mode no longer shows a play badge on video thumbnails; grid mode keeps it.

Fixed:
Search selection no longer collides for identical names in different folders.
Back in edit mode returns to the preview after confirming unsaved changes.
Long server URLs are ellipsized on the account and edit-server screens.
Download name collisions append a number on Android 9 and below instead of overwriting.
Editor line numbers stay aligned on wrapped visual lines.

## 中文

新增：
长按多选 + 常驻底部操作条，以及统一的新建/上传 FAB。
列表和网格两种视图，网格使用卡片式大图，缩略图更清晰。
每个目录独立记忆排序、视图和滚动位置。
多文件合集分享、二维码卡片图片和分享永久删除。
统一的文档界面，支持原地编辑、标题随滚动收起、按文件记忆换行。
图片和视频独立全屏，视频结束或关闭后恢复音乐。
统一的目录选择器，支持切换服务器和逐级创建不存在的目录。
客户端更新检查，在客户端和服务端版本旁显示新版本提示。
识别 APK，并补齐电子书、字体、磁盘镜像、设计文件、Torrent 等类型。

完善：
文件名中间省略时保留后缀，覆盖 APK、AAB、EPUB、字体、磁盘镜像、设计文件、Torrent、字幕等格式。
文本和 Markdown 的预览与编辑统一为 15sp/23sp 字号和 16dp 内容边距。
超过 40k 字符的代码在编辑时关闭语法着色，避免大文件卡顿。
分享卡片去掉原始网址，有效期和扫码提示加大、居中并留出底部安全边距。
“我的”页面用紧凑圆环显示配额，版本卡片放在服务器卡片下面。
文档页面主题现在同时覆盖通知栏、顶部标题栏和底部状态栏。
列表模式不再显示视频播放角标，网格模式保留。

修复：
搜索结果多选按 root + 路径区分，不再混淆同名文件。
编辑模式返回键确认放弃后会回到预览，不再直接退出。
用户卡片和编辑服务器页的长网址会自动省略。
Android 9 及以下下载同名文件自动加序号，不再覆盖。
编辑器换行后行号仍保持正确对齐。
