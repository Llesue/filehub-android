# FileHub Android 0.1.2

0.1.2 是一次大规模的浏览、分享与文档体验更新。

## 浏览

- 长按多选 + 常驻底部操作条：移动、删除、分享、更多；移除了文件行右键菜单。
- 右下角 FAB 统一新建 / 上传 / 拍照；下拉刷新。
- 列表 / 网格双视图，手机 2 列、平板 3–4 列。
- 每个目录独立记忆排序、视图和滚动位置，重启后恢复。
- 更紧凑的底部导航。
- 识别 APK，并补齐电子书、字体、磁盘镜像、设计文件、Torrent 等类型。

## 分享

- 多文件合集分享（仅文件、最多 100 个、只读）。
- 二维码卡片图片：显示分享内容、favicon、有效期和密码提示；可转发、复制链接、长按保存。
- 分享列表支持永久删除，与撤销分开。
- 远程 root 不提供分享入口（服务端不支持）。

## 文本

- 预览与编辑合并为同一套文档界面，原地切换。
- 统一底部状态栏：编码、字数、换行符、大小；右上角更多菜单提供撤销/重做。
- 编码不确定时可点按循环、长按选择。
- 文本/Markdown 15sp 基线，代码 14sp 等宽。

## 媒体

- 图片独立全屏模式：单击切换，双击放大并进入全屏。
- 视频控件隐藏即全屏，状态栏一起隐藏。
- 视频结束后恢复此前播放的音乐。

## 目录选择器

- 移动/复制、相册同步、目录同步共用同一个选择器。
- 支持切换服务器、面包屑、手动路径、分页、新建文件夹、只读/离线提示。
- 目标目录不存在时二次确认并逐级创建；禁止移动到自身或子目录。

## 更新检查

- “我的 → 版本”显示客户端与服务端的新版本提示，24 小时缓存，可手动刷新。

## 其他

- 搜索结果支持多选、下载和删除。
- Android 9 及以下下载同名文件自动加序号，不再覆盖。

---

安装包与 SHA-256 见发布资产。最低 Android 8.0（API 26）。
