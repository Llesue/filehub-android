# FileHub Android 0.1.9

This is a follow-up to 0.1.8 and includes all 0.1.8 fixes.

## English

Fixed:
- Android 13+ photo and folder sync now request notification permission and show an "Enable sync notifications" card when it is missing. Granting it keeps the foreground sync notification visible so manual sync can continue after the app UI is closed.
- Foreground promotion failures are logged as a warning instead of being silently ignored.

## 中文

本版是 0.1.8 的补丁，包含 0.1.8 的全部修复。

修复：
- Android 13+ 的相册和目录同步现在会请求通知权限；权限缺失时显示“开启同步通知”卡片。授予后前台同步通知可见，手动同步在关闭 App 界面后也能继续。
- 前台服务提升失败会记录为警告日志，不再静默忽略。
