# FileHub Android 0.1.4

## English

Highlights:
Designed the phone landscape shell and the tablet/car two-pane mode, keeping the same layout after rotating to portrait.
Added a foreground-only SSE connection for real-time job, quota, root, version and settings updates, with polling fallback.
Shipped a large batch of fixes across PDF zoom, image preview, root changes, uploads and navigation.

New:
The app keeps a foreground-only realtime event stream for job progress, quota, server version, remote root health, root order and settings, with polling fallback for older servers.
Phone landscape uses a permanent left column with the server selector, roots, share management, quota and versions, while the right pane follows folder drill-down.
Car and tablet layouts use a fixed root sidebar and a right-hand file browser with 1–4 adaptive list columns.
Tablet and car layouts keep the same two-pane shell in portrait and landscape, with a narrower sidebar and fewer file columns.
Tablet list rows are taller with larger thumbnails and more spacing.
The tablet top bar contains the server picker, search, list/grid switch, sort, theme toggle, upload and avatar, and the avatar opens a narrow My popover.
Selecting a folder on tablet navigates inside the right pane while the sidebar root selection stays fixed.
Tablet text editing opens in a modal editor with autosave.
Images and video open in the existing fullscreen viewer and player.
PDFs open in the fullscreen viewer with fit-page pinch zoom, a page rail capped at eight visible numbers and full-width landscape pages.
Tablet PDF pages scale inside a fixed viewport, so zooming out stops at the whole page and the page rail stays fixed.
Tablet image previews on Android 11 and below use a dark gradient lightbox instead of a thumbnail backdrop.
Phone landscape drops the bottom tab bar and drawer in favour of the permanent left column.
Offline remote roots are collapsed by default and dimmed when expanded.

Improved:
JSON, XML, HTML, CSS and SQL get lightweight syntax colours in preview and edit, using the built-in highlighter instead of a new dependency.
The inline preview pane was removed; text always uses the unified document screen.
File grids adapt from 2 to 6 columns, and root cards adapt up to 4 outlined columns on wide screens.
Upload, selection and creation actions move to the top in landscape and wide layouts.
Uploads that collide with an existing name are always auto-renamed.
The directory picker hides offline roots.
Document text is capped at 880dp, and the tablet header is a single row with a separate breadcrumb.
Landscape My actions use four columns when space allows, and the logout button is centred.
Deleting a root currently being browsed returns to the root list instead of leaving stale contents.
The tablet sidebar shows roots, offline roots, shares, quota, server/client versions and update hints in one column.

Fixed:
PDF pinch-out no longer shrinks the whole pager viewport; it stops at the fitted page scale.
Deleting the root currently being browsed returns to the root list instead of leaving stale contents.
Moving or copying files from subdirectories sends the correct root-relative paths.
Uploads that collide with an existing name are auto-renamed instead of overwritten or skipped.

## 中文

本次亮点：
设计手机横屏模式，以及车机/平板双栏模式，旋转到竖屏后仍保持同一套界面。
接入前台 SSE 实时连接，任务、配额、目录、版本和设置自动刷新，旧服务端回退轮询。
集中修复 PDF 缩放、图片预览、root 变更、上传和导航等一批问题。

新增：
前台保持实时事件流，任务进度、配额、服务端版本、远程目录状态、目录顺序和设置自动刷新；旧服务端自动回退到轮询。
手机横屏改成固定左栏：服务器选择、root、分享管理、配额和版本在一列，右栏随目录逐级下钻。
车机和大平板使用固定 root 侧栏 + 右侧文件浏览器，列表按宽度自适应 1–4 列。
平板和车机旋转到竖屏后保持同一套双栏界面，侧栏收窄、文件列表减少列数。
平板列表行更高，缩略图更大，行间距更宽。
平板顶栏包含服务器选择、搜索、列表/网格、排序、主题、上传和头像，头像打开窄版“我的”弹出框。
平板点文件夹只在右侧进入，左侧 root 选中状态不变。
平板文本编辑改为模态编辑器，停止输入后自动保存。
图片和视频进现有全屏查看器与播放器。
PDF 进全屏查看器，支持按页适配的双指缩放，左侧页码栏最多同时显示 8 个页码，横屏页面撑满宽度。
平板 PDF 页面在固定视口内缩放，缩到整页就停止，页码栏不跟着缩放。
Android 11 及以下的平板图片预览改用深灰渐变灯箱，不再使用缩略图背景。
手机横屏不再使用底部三 tab 和抽屉，改成固定左栏。
“位置”页的离线远程目录默认折叠，展开后半透明显示。

完善：
JSON、XML、HTML、CSS、SQL 在预览和编辑里都有轻量语法颜色，用内置实现，不新增依赖。
删除了内嵌预览栏，文本始终使用统一文档页。
文件网格从固定 2–4 列改成按宽度自适应 2–6 列，宽屏根目录卡片最多 4 列。
横屏和宽屏把上传、选择和新建操作移到顶部。
上传遇到同名文件一律自动改名，不覆盖、不跳过。
目录选择器不再显示离线目录。
文档正文最大 880dp，平板顶栏单行并带独立面包屑。
横屏“我的”操作按钮在空间足够时排成四列，退出登录按钮居中。
删除正在浏览的 root 后退回 root 列表，不再停留在过期内容。
平板侧栏在同一列显示 root、离线 root、分享管理、配额、服务端/客户端版本和更新提示。

修复：
PDF 双指缩小不再缩放整个翻页视口，缩到整页适配比例就停止。
删除正在浏览的 root 后退回 root 列表，不再停留在过期内容。
从子目录移动或复制文件时发送正确的完整相对路径。
上传遇到同名文件自动改名，不覆盖、不跳过。
